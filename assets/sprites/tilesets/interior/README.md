# Tileset de interiores

`spr_tileset_sunnysideworld_16px.png` vem do pacote **Sunnyside World** (Daniel Diggle): https://danieldiggle.itch.io/sunnyside

É usado pela cena `scenes/levels/biblioteca.tscn` (script `src/levels/biblioteca.gd`) para desenhar piso, paredes, tapetes e móveis. As posições dos tiles e as regiões dos móveis estão no começo do script.

Antes de publicar este repositório, confira os termos de uso do pacote na página acima. Este pacote é pago e normalmente não pode ser redistribuído em repositório público.
