# Arte da Mesa de Alquimia

Imagens derivadas do pacote **Sunnyside World** (Daniel Diggle): https://danieldiggle.itch.io/sunnyside

- `panel_dark.png`, `panel_light.png`, `panel_white.png`: molduras de 9 fatias montadas a partir de `UI/9slice_box_white` (ampliadas 3x).
- `disc_slot.png`: disco de item (`UI/itemdisc_01`) ampliado 6x.
- `flask_32.png`, `flask_64.png`, `jar_32.png`, `jar_64.png`: frasco e jarro recortados do tileset `spr_tileset_sunnysideworld_16px.png`, convertidos para tons de cinza e ampliados 2x/4x. O código (`src/ui/crafting_ui.gd`) pinta cada um com a cor do grupo da substância.
