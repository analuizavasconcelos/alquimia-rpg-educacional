# 🎮 Proposta de Plataforma de Jogo Educacional Estilo RPG

> **Trabalho de Conclusão de Curso (TCC)**  
> Jogo educacional desenvolvido na engine Godot 4.4 com foco no ensino de conceitos de Química através de uma experiência imersiva e gamificada.

## 📋 Sobre o Projeto

Plataforma de jogo educacional estilo RPG com temática de fantasia medieval, desenvolvida na engine Godot 4.4. O jogo utiliza princípios de gamificação para promover aprendizado passivo-ativo, incorporando elementos como progressão de conhecimentos, sistema de recompensas, exploração aberta e interação narrativa.

O conteúdo educacional é apresentado de forma natural durante diálogos com NPCs, onde termos relevantes são destacados e desbloqueados automaticamente no glossário, permitindo que o jogador absorva conhecimentos enquanto realiza atividades típicas do gênero RPG.

A plataforma foi concebida como um sistema modular e expansível, permitindo a integração futura de novos módulos educacionais sem necessidade de reestruturar o núcleo do sistema.

## 🚀 Como Executar

### Pré-requisitos
- **Godot Engine 4.4** ou superior
- Windows, Linux ou macOS

### Executar no Editor
1. Abra o projeto no Godot 4.4
2. Pressione **F5** ou clique em **Play** (▶️)
3. O menu principal será exibido

### Controles

#### Desktop
- **WASD** ou **Setas**: Mover o personagem
- **E** ou **Clique**: Interagir com NPCs e objetos
- **ESC**: Abrir menu rápido

#### Mobile
- **Joystick Virtual**: Mover o personagem
- **Botão Interagir**: Interagir com NPCs e objetos
- **Botão Menu**: Abrir menu rápido


## 🎯 Características Principais

- ✅ Movimentação top-down em 4 direções
- ✅ Sistema de diálogo com NPCs baseado em JSON
- ✅ Sistema de conhecimento com desbloqueio automático
- ✅ Glossário de conhecimentos desbloqueados
- ✅ Sistema de save/load
- ✅ Suporte mobile (controles touch)
- ✅ Transição entre cenas (vilarejo e masmorra)

## 🛠️ Tecnologias

- **Engine:** Godot 4.4
- **Linguagem:** GDScript
- **Dados:** JSON (diálogos e conteúdo educacional)
- **Plataformas:** PC (Windows, Linux, macOS) e Android
